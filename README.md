# 🎮 Ретро Игровой Хаб (Retro Game Hub)

Full-stack одностраничное веб-приложение (SPA), включающее классические аркадные и логические игры с поддержкой мультиплеера в реальном времени, глобальной таблицей рекордов и безопасной системой авторизации.

## 🚀 Основные возможности

*   **4 классические игры:** Крестики-нолики, Камень-Ножницы-Бумага, Сапер и Неоновая Змейка.
*   **Мультиплеер в реальном времени:** Играйте в Крестики-нолики по сети против других игроков с помощью WebSockets.
*   **Безопасная аутентификация:** Система регистрации и входа пользователей на базе JWT-токенов.
*   **Глобальная таблица рекордов:** Сохраняйте свои победы и соревнуйтесь с другими игроками во всех играх.
*   **Кастомизируемый интерфейс:** Перетаскивание карточек игр (Drag-and-Drop), переключение светлой/темной темы и 8 неоновых цветовых палитр на выбор.
*   **Мультиязычность:** Интерфейс переведен на 10 языков (Английский, Испанский, Французский, Китайский, Русский, Казахский, Белорусский, Украинский, Узбекский).
*   **Аудио движок:** Программно синтезируемые ретро-звуковые эффекты с использованием Web Audio API.

## 🛠️ Стек технологий

**Frontend (Клиентская часть):**
*   Vanilla JavaScript (ES6+)
*   HTML5 & CSS3 (CSS Переменные, Grid, Flexbox)
*   SignalR Client (WebSockets)

**Backend (Серверная часть):**
*   C# / ASP.NET Core Web API
*   SignalR (Real-time хаб для мультиплеера)
*   JWT Аутентификация & Хэширование паролей (BCrypt)

**База данных:**
*   PostgreSQL
*   Dapper (Микро-ORM для быстрых SQL-запросов)

## ⚙️ Инструкция по локальному запуску

### 1. База данных (PostgreSQL)
Создайте новую базу данных с именем `Leaderboard` и выполните следующий SQL-скрипт для создания необходимых таблиц:
```sql
CREATE TABLE Users (
    Id SERIAL PRIMARY KEY,
    Username VARCHAR(50) UNIQUE NOT NULL,
    PasswordHash VARCHAR(255) NOT NULL
);

CREATE TABLE Leaderboard (
    Id SERIAL PRIMARY KEY,
    PlayerName VARCHAR(50) NOT NULL,
    GameName VARCHAR(50) NOT NULL,
    Wins INT DEFAULT 0,
    LastPlayedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
